## 1. Wire rules, references and bounds

The notation below defines exact closed JSON records; + adds the listed fields, | is a discriminated union, ? is a required nullable field, [T] is an array. No extension maps, duplicate keys, coercion, nonfinite numbers, secret values or caller-assigned native IDs. Version fields are literal 1. All strings are UTF-8; S(n) means at most n bytes, nonempty unless expressly stated.

- Id = 32 lowercase hex; H = 64 lowercase hex; G = 40 lowercase hex; N = integer 0..9007199254740991; P = N >=1; I = signed integer -9007199254740991..9007199254740991; Key = S(256); Ref = S(128).
- Q = {num:N,den:P}; SignedQ = {num:I,den:P}; rationals reduced, zero denominator forbidden; exact integer intermediates, bound-refusal if reduced result cannot fit, never float rounding of source time. Session = {session_id:Ref,thread_id:Ref,epoch:P}; Scope = local_only|public_synthetic|private_cloud_authorized.
- NativeRef = {backend_id:Id,receipt_id:Id,sha256:H}; R<T> = {v:1,id:Id,key:Key,request_sha256:H,body:T,sha256:H}; Found<T> = {v:1,found:bool,value:R<T>?}; found iff value nonnull. NativeRef typed unions resolve native stored kind plus exact digest, never caller-chosen coercion.

Backend ID is durable database identity, not process ID. NativeRef resolves the exact original typed R<T> in that backend; field type fixes T. It is never a bearer credential, URL, filesystem path or proof by itself. Missing lookup is unknown, not not-applied/settled.
Canonical bytes use sorted object keys, compact separators, UTF-8, exact integers and required nulls. H(Type,record) = SHA256(UTF8("kinaiya.media.v1/" + Type + "\0") || canonical(record)); omit only the named self-sha256 field, never nested digests. R<T> omits only its outer sha256; Profile, Capability and page rules below are explicit. Binary/source/asset/code/schema digests hash exact bytes without this JSON domain. Qualification is separate to avoid hash cycles.
Ordinary control/request/record/page: <=65536 encoded bytes, depth<=24, <=8192 JSON nodes (every scalar/container counts; keys do not). Arrays also obey their specific counts. Byte budget wins. Existing nested SpeechWindow/AudioWindow/WindowDecision/DeliveryRequest/ModelPin and legacy request caps/validators are unchanged and checked independently.
Only operation-specific Submit/Steer/Interrupt/Queue admission, R<OriginalAdmission>, AnchorAdmission embedding legacy TaskRequest, and their exact lookup receipts may use <=262144 bytes, depth<=32, <=32768 nodes. An embedded legacy canonical request remains <=65536 decoded bytes and <=87384 base64 bytes, with all old DTO caps unchanged; new metadata independently remains <=65536/depth24/nodes8192. Persisted original admission envelope also fits this bound; reject before effects if it cannot. No general large-record exemption.
Manifest pages <=64 units; alignment pages <=128 pairs; word pages <=128 words; record pages <=64 records; range lists <=64; track lists <=8; format lists <=16; children <=16; errors are fixed enums. Pagination never discards history, resets an intent, or asserts that an incomplete page set is complete.

- Error = {v:1,error:bad_packet|denied|unknown_ref|stale|expired|unsupported|bound|capacity|unavailable|conflict}; no arbitrary exception text. 400 malformed,403 denied,404 unknown,409 stale/conflict,410 expired bytes,413 bound,415 unsupported,429 capacity,503 unavailable.

Every mutation has a Key; same key and canonical request return exact original R<T>, different bytes conflict. Key replay returns history without renewing authority. Lookup/control reply deadline 5s, native admission 25s, upload chunk 60s; none waits for ASR/inference/physical cleanup. Timeout never proves failure or releases an action/reservation.
